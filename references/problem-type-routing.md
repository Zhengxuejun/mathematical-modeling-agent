# 题型路由与模型门禁 / Problem Type Routing

本文件用于防止数学建模智能体“看见数据就套模型”。读题后先识别题型，再进入对应中间表示、推荐模型和质量门禁。

## 1. 路由原则

一道题可以同时属于多个题型。路由时按“小问”而不是整题粗暴归类。

输出格式：

```text
小问：
核心对象：
题型标签：优化 / 预测 / 评价 / 仿真 / 统计推断 / 阈值事件 / 分类筛查 / 机理建模 / 图网络 / 时空运动
关键输出：
推荐模型：
禁忌模型：
最低验证：
```

## 2. 常见题型路由表

| 题型 | 识别信号 | 推荐模型 | 禁忌/风险 |
|---|---|---|---|
| 资源优化 | 最小成本、最大收益、路径、排班、分配 | LP/IP/MIP、启发式、动态规划、VRP | 只做评价不输出决策变量 |
| 时间序列预测 | 时间趋势、未来值、周期 | ARIMA/指数平滑/回归/机器学习 | 没有时间切分就随机交叉验证 |
| 综合评价 | 排名、等级、指标体系 | 熵权法、AHP、TOPSIS、PCA | 权重没有解释，量纲未标准化 |
| 统计相关/显著性 | 相关性、影响因素、显著性 | 回归、混合效应、GEE、非参数检验 | 重复测量当独立样本 |
| 阈值达标时间 | 首次达到、超过阈值、最早时间点 | 生存分析、达标概率曲线、分位数回归、风险最小化 | 只预测连续值不转化为决策时点 |
| 分类筛查 | 异常判定、阳性/阴性、故障识别 | 逻辑回归、树模型、随机森林、XGBoost、阈值规则 | 数据泄漏、只看 Accuracy、忽略类别不平衡 |
| 机理物理建模 | 运动轨迹、力学、光学、电磁、化学 | 微分方程、几何约束、数值仿真、参数反演 | 只用黑箱拟合不写物理量单位 |
| 多体时空优化 | 多目标、多装备、多时段、多约束 | 分层优化、仿真-优化、遗传算法/粒子群/模拟退火 | 未建立时空坐标系和碰撞/约束检查 |
| 图网络 | 节点、边、路径、连通性、传播 | 最短路、最大流、中心性、社区发现 | 把网络问题硬转成普通表格回归 |
| 图像/视频/姿态 | 视频、轨迹点、关键点、动作质量 | 信号处理、轨迹平滑、特征提取、分类/回归 | 不做帧率、坐标系、噪声检查 |

## 3. 重复测量门禁

如果同一对象存在多次观测，例如同一孕妇多次检测、同一设备多次采样、同一运动者多次试验：

- 不得默认把所有行当独立样本；
- 显著性检验应考虑主体内相关；
- 优先考虑混合效应模型、GEE、聚类稳健标准误、按主体划分训练测试集；
- 交叉验证不能把同一主体的记录同时分到训练集和测试集。

## 4. 阈值达标时间门禁

触发词：首次达到、最早达标、超过阈值、检测时点、风险最小。

必须明确：

1. 阈值定义，例如 Y 染色体浓度 ≥ 4%；
2. 时间变量单位和解析方式；
3. 未达标/右删失样本如何处理；
4. 风险函数如何平衡“过早失败”和“过晚发现”；
5. 输出的是可执行时点，而不是只有预测曲线。

可选方法：

- Kaplan-Meier / Cox / AFT 生存模型；
- 达标概率曲线 `P(y >= threshold | t, x)`；
- 分位数回归估计达到阈值的保守时点；
- Monte Carlo 检测误差扰动；
- 按分组最小化期望风险。

## 5. 分类筛查门禁

触发词：异常判定、疾病筛查、故障识别、阳性/阴性、非整倍体。

必须检查：

- 标签列到底是哪一列；
- 是否有事后结果列，是否允许作为标签；
- 哪些特征在真实判定时可用；
- 是否存在类别不平衡；
- 是否需要偏重召回率、特异度、阴性预测值或精确率。

最低报告指标：

- 混淆矩阵；
- Recall/Sensitivity；
- Specificity；
- Precision；
- F1；
- ROC-AUC 或 PR-AUC；
- 阈值选择理由。

禁止：

- 只报告 Accuracy；
- 把目标标签或目标标签的直接派生列放进特征；
- 用全数据调参后再报告同一数据上的高分；
- 在医学筛查类问题中忽略假阴性成本。

## 6. 物理/机理题门禁

如果题目包含三维坐标、速度、方向、投放、起爆、干涉、波长、折射率等机理变量：

- 先建立坐标系、单位和时间轴；
- 明确状态变量和控制变量；
- 写出运动/光学/物理方程；
- 先做题目给定参数的 sanity check；
- 优化前先能复现实例/问题一。

## 7. 2025 国赛 C 题路由示例

- 问题 1：重复测量统计相关 + 显著性检验；推荐混合效应/GEE/稳健回归。
- 问题 2：BMI 分组 + 阈值达标时间 + 风险最小化；推荐达标概率曲线/生存分析/分组动态规划。
- 问题 3：多因素阈值达标 + 分组决策；推荐多变量达标模型 + 误差 Monte Carlo。
- 问题 4：女胎异常分类筛查；推荐可解释分类模型 + 类别不平衡评估 + 数据泄漏检查。
