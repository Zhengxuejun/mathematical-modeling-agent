# 数学建模方法库 / Model Library

本文件作为 `mathematical-modeling-agent` 的方法检索参考。使用时先判断问题类型，再选择候选模型，不要机械套用。

## 1. 方法选择总则

### 1.1 选择顺序

1. **题目目标**：优化、预测、评价、解释、分类、仿真、调度？
2. **数据条件**：有无数据、样本量、时间序列/截面/空间网络、字段质量。
3. **约束结构**：线性/非线性、连续/离散、确定/随机、单目标/多目标。
4. **输出要求**：数值答案、排序、策略、路线、预测区间、图表、政策建议。
5. **可验证性**：是否能用基线、交叉验证、敏感性分析或现实常识检验。

### 1.2 建模禁忌

- 不要在没有数据支撑时硬上机器学习。
- 不要在变量和单位不清时直接写目标函数。
- 不要用复杂模型掩盖题目没有回答的问题。
- 不要只给模型名称，必须给变量、目标函数、约束和求解路径。
- 不要把评价模型当成因果模型，TOPSIS/AHP/熵权只说明排序，不说明因果。

## 2. 优化类模型

### 2.1 线性规划 LP

**适用**：资源分配、运输计划、生产计划、成本最小化、收益最大化。

**形式**：

```math
\max/min \quad c^T x
```

```math
s.t. \quad Ax \le b, \quad x \ge 0
```

**检查点**：目标和约束是否线性；单位是否一致；解是否符合现实容量约束。

**Python**：`scipy.optimize.linprog`、`pulp`、`cvxpy`。

### 2.2 整数规划 / 0-1 规划 / MIP

**适用**：选址、是否选择、排班、路径选择、设施开闭、任务分配。

**典型变量**：

```math
x_i \in \{0,1\}
```

表示是否选择方案/设施/路径。

**Python**：`pulp`、`ortools`、`cvxpy`，大规模问题可用启发式。

### 2.3 多目标规划

**适用**：成本、时间、风险、收益、碳排放等多目标冲突。

**常见处理**：

- 加权和：`min w1*f1 + w2*f2 + ...`
- ε-约束：主目标优化，其他目标转为约束。
- Pareto 前沿：展示权衡关系。

**验证**：权重敏感性必须做，否则结论不稳。

### 2.4 动态规划 DP

**适用**：阶段决策、库存控制、路径阶段优化、资源随时间分配。

**要素**：阶段、状态、决策、状态转移、边界条件。

```math
V_t(s)=\min_a \{ C_t(s,a)+V_{t+1}(T(s,a)) \}
```

### 2.5 VRP/TSP/路径规划

**适用**：车辆配送、旅游路线、巡检路径、物流选线。

**常见约束**：车辆容量、时间窗、服务时间、里程、碳排放、车辆数。

**方法**：

- 小规模：整数规划/OR-Tools。
- 中大规模：遗传算法、模拟退火、蚁群、局部搜索、Savings 算法。

**相关技能**：绿色物流/VRP 问题优先加载 `green-logistics-vrp`。

## 3. 预测类模型

### 3.1 回归模型

**适用**：连续变量预测、影响因素分析、趋势拟合。

**模型**：线性回归、岭回归、Lasso、多项式回归、广义线性模型。

**验证**：训练/测试划分、残差分析、R²、MAE、RMSE、MAPE。

### 3.2 时间序列

**适用**：按时间变化的需求、价格、客流、污染物、销量等。

**方法**：

- 简单趋势：移动平均、指数平滑。
- 统计模型：ARIMA/SARIMA。
- 机器学习：滞后特征 + 随机森林/XGBoost/SVR。

**检查点**：时间顺序不能打乱；不能用未来信息预测过去。

### 3.3 灰色预测 GM(1,1)

**适用**：小样本、单调趋势、数据较少的预测题。

**风险**：对波动数据效果差；必须做后验差检验或误差评价。

### 3.4 分类/聚类

**适用**：风险等级、区域类型、用户/样本分群。

**方法**：KMeans、层次聚类、GMM、决策树、随机森林、SVM。

**验证**：轮廓系数、CH 指数、混淆矩阵、F1、稳定性分析。

## 4. 综合评价类模型

### 4.1 AHP 层次分析法

**适用**：专家判断、指标层次清楚、主观权重合理的评价。

**步骤**：构建层次结构 → 判断矩阵 → 一致性检验 CR < 0.1 → 权重。

**风险**：主观性强；必须说明判断依据。

### 4.2 熵权法

**适用**：用数据离散度确定客观权重。

**优点**：减少主观赋权。

**风险**：离散度大不等于重要性高，只代表区分度强。

### 4.3 TOPSIS

**适用**：多指标排序、优劣评价。

**步骤**：指标同向化 → 标准化 → 加权 → 正/负理想解 → 距离 → 贴近度。

**常用组合**：熵权-TOPSIS、AHP-TOPSIS。

### 4.4 模糊综合评价

**适用**：评价等级模糊、指标难以精确量化，如满意度、风险等级。

**要素**：因素集、评价集、隶属度矩阵、权重向量。

## 5. 统计分析与因果推断

### 5.1 描述统计与相关分析

**必须先做**：均值、方差、分布、异常值、缺失值、相关矩阵。

### 5.2 假设检验

**适用**：比较两组或多组差异是否显著。

**方法**：t 检验、卡方检验、ANOVA、Mann-Whitney U。

### 5.3 回归诊断

检查：多重共线性 VIF、残差正态性/异方差、异常点、稳健标准误。

### 5.4 因果模型

DID、PSM、IV、RDD 仅在题目和数据满足识别条件时使用。没有外生冲击/处理组对照组时，不要强行写 DID。

## 6. 仿真类模型

### 6.1 Monte Carlo

**适用**：参数不确定、风险分布、概率估计。

**步骤**：定义输入分布 → 重复抽样 → 计算输出 → 分布/置信区间。

### 6.2 排队论

**适用**：服务窗口、交通排队、系统等待时间。

**常见模型**：M/M/1、M/M/c。

### 6.3 系统动力学

**适用**：反馈回路、库存-流量、长期演化。

**要素**：存量、流量、反馈、延迟。

### 6.4 Agent-Based Simulation

**适用**：个体行为导致整体涌现，如人群疏散、传播、交通行为。

**风险**：参数多，必须做敏感性分析。

## 7. 网络与图模型

**适用**：交通网络、供应链、社交/信息传播、电网/管网。

**方法**：

- 最短路：Dijkstra/Floyd。
- 最小生成树：Kruskal/Prim。
- 最大流/最小割：Ford-Fulkerson/Edmonds-Karp。
- 中心性：度、介数、接近、PageRank。
- 社区发现：Louvain、谱聚类。

## 8. 组合建模套路

### 8.1 预测 + 优化

先预测需求/流量/风险，再把预测结果输入优化模型。

示例：预测未来订单量 → 车辆路径优化。

### 8.2 评价 + 优化

先评价候选方案或区域，再对高优先级对象做资源分配。

示例：熵权-TOPSIS 评估城市韧性 → 多目标规划分配资金。

### 8.3 聚类 + 分组建模

先对样本分群，再分别建模。

示例：城市按发展水平聚类 → 各类城市分别预测碳排放。

### 8.4 仿真 + 敏感性

用仿真生成结果分布，再分析关键参数影响。

## 9. 快速匹配表

| 题目关键词 | 优先方法 |
|---|---|
| 最优、最小成本、最大收益 | LP/MIP/NLP/多目标规划 |
| 是否选择、开不开、派不派 | 0-1 规划/MIP |
| 路径、配送、车辆、时间窗 | VRP/TSP/网络优化 |
| 排名、评价、综合水平 | 熵权法/AHP/TOPSIS/模糊评价 |
| 未来趋势、需求预测 | 时间序列/回归/机器学习 |
| 风险、不确定性、概率 | Monte Carlo/情景分析 |
| 服务窗口、等待时间 | 排队论/仿真 |
| 传播、扩散、人群行为 | 元胞自动机/ABM/网络模型 |
| 影响因素 | 回归/统计检验/因果推断 |

## 10. 最低交付要求

每次选择模型后，必须落地为：

1. 为什么选它；
2. 变量与参数；
3. 目标函数/评价函数；
4. 约束或算法步骤；
5. Python 求解路径；
6. 结果验证方式；
7. 模型局限性。
