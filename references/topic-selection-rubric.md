# 选题决策评分器 / Topic Selection Rubric

本文件用于国赛、美赛、校赛开始后的前 1 小时选题。目标是避免被“看起来高级”的题诱导，选择能在规定时间内稳定闭环的题。

## 1. 评分维度

每题按 7 个维度评分，每项 1–5 分。总分 35 分，可换算百分制。

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| 数据可用性 | 附件完整、字段清晰、格式常规 | 有附件但需较多清洗 | 数据缺失/格式复杂/难读取 |
| 可建模性 | 目标、变量、约束明确 | 可建模但需较多假设 | 目标模糊，难落地 |
| 可验证性 | 有 baseline、指标、常识或测试集 | 只能部分验证 | 结果难以判断对错 |
| 计算风险 | 常规 Python 可完成 | 需要优化/图像/仿真但规模可控 | 依赖重库/大规模/硬件风险高 |
| 写作空间 | 图表、解释、建议充分 | 有一定写作空间 | 只能堆公式或结果单薄 |
| 创新空间 | 可自然加入改进模型/鲁棒性 | 有少量扩展 | 难创新或创新牵强 |
| 时间风险 | 24h 内可出 MVP | 需要 36h+ 才稳 | 很可能 72h 内不闭环 |

## 2. 总分解释

| 百分制 | 建议 |
|---:|---|
| ≥85 | 优先选择，稳健冲奖 |
| 75–84 | 可选，需控制复杂度 |
| 65–74 | 风险较高，除非团队强匹配 |
| <65 | 不建议选择 |

## 3. 必要否决项

出现以下任一情况，即使总分高也要谨慎：

- 关键附件无法读取或缺失；
- 题目要求提交特定结果文件但模板不清；
- 需要大量领域知识且无法快速补齐；
- 需要 GPU/大型仿真/复杂视频处理而本机资源不足；
- 结果几乎无法验证；
- 团队无人能写核心代码。

## 5. 题型偏好建议

- 稳健型队伍：优先数据清晰、统计/评价/优化可验证的题；
- 编程强队伍：可选图像/视频/仿真/大规模优化，但必须先跑 MVP；
- 写作强队伍：可选社会经济/管理评价类题，但必须有可靠数据和指标；
- 物理强队伍：可选机理建模题，但问题一必须能先 sanity check。

## 6. 2025 国赛示例性判断

仅作选题方法示例，不代表官方评价：

- A 题烟幕干扰弹：物理/三维时空优化强，建模上限高，但几何和优化细节风险高；
- B 题碳化硅厚度：机理清晰，数据较规整，但需要光学干涉推导；
- C 题 NIPT：数据表清晰，统计建模与筛查路线明确，但重复测量、风险函数和数据泄漏门禁要求高。

最终仍以团队能力和附件审计结果为准。
