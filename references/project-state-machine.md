# 建模项目状态机 / Project State Machine

本文件把数学建模任务从“线性流程”升级为可检查、可回退、可交付的项目状态机。

## 1. 状态总览

```text
S0 材料获取
S1 题目解析完成
S2 数据审计完成
S3 基线模型完成
S4 核心模型完成
S5 敏感性/鲁棒性分析完成
S6 报告初稿完成
S7 一致性检查完成
S8 最终提交包完成
```

每个状态都必须有产物。没有产物就不能宣称状态完成。

## 2. 状态定义

### S0 材料获取

输入：题面、附件、模板、参考规则。  
产物：`inputs_manifest.md`。  
完成判据：所有题面列出的附件都被列入清单，缺失项明确标注。  
禁止：附件未审计就开始正式建模。

### S1 题目解析完成

输入：题面和附件说明。  
产物：`problem_analysis.md`。  
完成判据：每问目标、交付物、变量、约束、风险点已列出。  
禁止：只写背景，不列每问交付物。

### S2 数据审计完成

输入：原始附件。  
产物：`data_audit.csv/json`、字段单位表、缺失异常记录。  
完成判据：行列数、缺失率、异常范围、主体重复、单位问题已记录。  
禁止：直接在原始附件上手改。

### S3 基线模型完成

输入：清洗数据、题型路由。  
产物：baseline 代码、baseline 结果表/图。  
完成判据：每问至少有一个可运行、可解释、可对照的粗模型。  
禁止：未跑 baseline 就直接堆高级模型。

### S4 核心模型完成

输入：baseline 结果、模型设计。  
产物：核心模型代码、参数、结果表、主图。  
完成判据：核心模型真实运行，结果能回答题目，且不违反约束。  
禁止：只写公式不运行，或只给代码不解释。

### S5 敏感性/鲁棒性分析完成

输入：核心模型结果。  
产物：敏感性表/图、鲁棒性对照、误差分析。  
完成判据：关键参数/权重/阈值至少一种扰动，结论稳定性被说明。  
禁止：把无关参数扰动当敏感性分析。

### S6 报告初稿完成

输入：题目解析、模型、结果、图表。  
产物：`report.md/docx/pdf` 初稿。  
完成判据：摘要占位、每问章节、结果分析、优缺点、附录齐全。  
禁止：最后才开始写报告。

### S7 一致性检查完成

输入：报告、代码、结果表、图表、附件。  
产物：`consistency_check.md`。  
完成判据：题目-结论、公式-代码、图表-正文、摘要-正文、提交文件一致性均检查。  
禁止：检查出关键不一致仍提交。

### S8 最终提交包完成

输入：终稿报告、支撑材料、代码、结果。  
产物：`07_提交包/`、`README_submit.md`、校验值。  
完成判据：`submission_manifest.json` 使用当前支持的 schema，明确标记 `package_valid=true`，不存在失败检查；manifest 文件清单全部存在且路径不越出提交包；`SHA256SUMS.txt` 对清单中每个文件的校验均通过。  
禁止：桌面散落文件、不知道最终版本在哪里。

S8 是经过验证的工程交付状态，不是“控制文件存在”状态。打包失败时不得覆盖上一份有效提交包，重复打包不得保留上一轮已禁用的代码、原始数据或旧报告。S8 也不证明数学模型必然正确，更不保证获奖；正式参赛还必须先冻结支撑 paper-ready 证据的 completed run，再通过 `contest_qc_gate.py --phase final` 与 competition-readiness 门禁。

## 3. 状态转移规则

```text
S0 -> S1：材料清单完成
S1 -> S2：题意拆解完成
S2 -> S3：数据可读取且审计完成
S3 -> S4：baseline 可运行
S4 -> S5：核心结果稳定且可解释
S5 -> S6：关键结果、图表、敏感性材料齐全
S6 -> S7：报告初稿完整
S7 -> S8：一致性问题清零或明确标注不可修复风险
```

允许回退：

- S4 结果异常 → 回 S2 查数据或 S3 查 baseline；
- S7 发现摘要数值不一致 → 回 S6 修报告；
- S7 发现公式代码不一致 → 回 S4 修模型/代码；
- S8 缺文件 → 回 S7/S6 补材料。

## 5. 状态机使用纪律

- 每次长任务回复时，至少说明当前处于哪个状态；
- 不能跳过 S2 数据审计；
- 不能跳过 S3 baseline；
- 如果用户要求“快速完成”，可压缩模型复杂度，但不能跳过题目交付物和数据审计；
- 任何“完成”都必须指向文件路径或可验证输出。
