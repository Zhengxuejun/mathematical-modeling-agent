# 数学建模论文/报告模板 / Report Template

本文件用于 `mathematical-modeling-agent` 技能生成数学建模论文、课程报告、国赛/美赛风格报告。实际写作时必须根据题目要求、学校/竞赛格式和用户指定模板调整。

## 1. 写作总原则

1. **摘要先给结果**：摘要不是背景介绍，要包含方法、关键数值结果、结论。
2. **逐问回答**：题目有几问，报告必须能清楚对应每一问。
3. **公式服务变量**：每个公式的变量都要在符号说明或正文解释。
4. **图表进入论证链**：图表不能孤立摆放，正文必须解释其含义。
5. **验证不可省略**：至少包含误差分析、敏感性分析或鲁棒性分析之一。
6. **优缺点具体**：不要写“模型简单、结果准确”这种空话。

## 3. 摘要模板

### 中文摘要

```text
摘要：针对【问题背景】中【核心矛盾/目标】的问题，本文围绕题目提出的【第1问、第2问、第3问】开展建模分析。

首先，针对【问题一】，本文构建了【模型名称】，以【核心变量/指标】为基础，通过【算法/方法】得到【关键结果1】。

其次，针对【问题二】，本文在【问题一结果/数据处理】基础上，引入【约束/评价指标/预测变量】，建立【模型名称】，结果表明【关键结果2，尽量给数值或排序】。

最后，针对【问题三】，本文进一步考虑【不确定性/多目标/现实约束】，采用【敏感性分析/鲁棒性检验/情景模拟】验证模型稳定性。结果显示【核心结论】。

本文模型的优点在于【具体优点】，不足在于【具体局限】，可在后续通过【改进方向】进一步提升。

关键词：【关键词1】；【关键词2】；【关键词3】；【关键词4】
```

### 摘要检查

- 是否回答了每一问？
- 是否出现模型名称？
- 是否有关键结果/数值/排序？
- 是否有验证或敏感性分析？
- 是否避免“具有重要意义”等空话？

## 6. 模型假设模板

```text
三、模型假设

假设1：【假设内容】。
理由：【为什么合理】。影响：【可能带来的偏差】。

假设2：【假设内容】。
理由：【为什么合理】。影响：【可能带来的偏差】。

假设3：【假设内容】。
理由：【为什么合理】。影响：【可能带来的偏差】。
```

常用假设类型：

- 数据采集误差在可接受范围内。
- 研究周期内外部政策/环境无突变。
- 个体行为服从某种平均规律。
- 忽略对结果影响较小的二阶因素。
- 成本/速度/需求等参数在短期内稳定。

禁止写无法辩护的假设，如“所有数据完全准确”“模型结果绝对可靠”。

## 9. 模型建立与求解模板

### 9.1 优化模型写法

```text
6.x 【问题x】模型建立

（1）变量定义
设 $x_i$ 表示【含义】，$i \in I$。

（2）目标函数
根据题目要求，本文以【成本最小/收益最大/风险最小】为目标：

$$
\min Z = \sum_{i \in I} c_i x_i
$$

（3）约束条件
资源约束：
$$
\sum_{i \in I} a_i x_i \le B
$$

需求约束：
$$
\sum_{i \in I} x_i \ge D
$$

变量取值：
$$
x_i \ge 0 \quad 或 \quad x_i \in \{0,1\}
$$

（4）求解方法
本文使用【scipy/pulp/ortools/cvxpy/启发式算法】进行求解。求解流程为：
1. 读取并清洗数据；
2. 构造目标函数与约束矩阵；
3. 调用求解器得到最优解；
4. 输出关键变量、目标函数值和可视化结果。

（5）结果解释
求解结果见表【编号】。结果表明【直接回答题目】。
```

### 9.2 预测模型写法

```text
6.x 【问题x】预测模型

（1）变量选择
以【目标变量】为因变量，以【特征变量】为自变量。

（2）模型形式
本文建立【模型名称】：

$$
y_t = f(x_{t,1}, x_{t,2}, ..., x_{t,p}) + \epsilon_t
$$

（3）训练与验证
将数据按时间/随机划分为训练集和测试集，使用【MAE/RMSE/MAPE/R²】评价预测效果。

（4）预测结果
模型在测试集上的误差为【数值】。未来【时间范围】预测结果为【结果】。
```

### 9.3 综合评价模型写法

```text
6.x 综合评价模型

（1）指标体系
从【维度1、维度2、维度3】构建评价指标体系。

（2）指标同向化与标准化
对于正向指标采用【公式】，对于负向指标采用【公式】。

（3）权重确定
采用【AHP/熵权法/组合赋权】计算权重，结果如表【编号】。

（4）综合得分
根据【TOPSIS/加权求和/模糊评价】计算综合得分，并得到排序。

（5）结果解释
排名靠前的对象具有【特征】，排名靠后的对象主要受【因素】影响。
```

## 14. 图表规范

### 表格

- 表号连续：表1、表2、表3。
- 表题在表上方。
- 单位写在表头或说明中。
- 正文必须引用表格：如“由表2可知……”。

### 图片

- 图号连续：图1、图2、图3。
- 图题在图下方。
- 坐标轴必须有名称和单位。
- 不使用无解释的默认图。
- 正文必须解释图中趋势或异常点。
